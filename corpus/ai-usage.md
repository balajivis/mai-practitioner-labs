# AI Tool Usage Policy (v2, effective 2026-06-15)
Employees may use company-approved AI tools (listed in VendorHub under "AI-Approved") for
drafting, coding, and analysis. Customer PII, unreleased financials, and security
architecture documents must never be pasted into ANY AI tool, approved or not.
AI-generated code merged to production requires the same review as human code, plus the
author must understand every line. Model outputs used in customer communications require
human review before sending. Teams deploying AI features must register them with the AI
Governance Board and pass an evaluation gate before launch; high-risk uses (hiring,
credit, legal) additionally require a documented human-in-the-loop checkpoint.
